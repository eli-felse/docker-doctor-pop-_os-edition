🩺 Docker Doctor Pop!_OS Edition

Paste the output of a few terminal commands and get an instant diagnosis of common Docker problems on Pop!_OS — plus the exact fix commands, ready to copy.

Run the checks below to see your Docker health.

1. Docker daemon

Is the Docker service actually running? This is the #1 cause of "Cannot connect to the Docker daemon" errors.

systemctl status docker --no-pager

2. Kernel modules

Docker needs overlay (storage driver) and br_netfilter (container networking) loaded in the kernel.

lsmod | grep -E 'overlay|br_netfilter'

3. Docker context

A leftover or misconfigured context (e.g. pointing at a dead remote endpoint) makes every docker command fail even when the daemon is fine.

docker context ls
